# Jarghe — Creator Studio

A Persian, mobile-first creator workspace for brainstorming video ideas, drafting titles, building downloadable thumbnail PNGs, and keeping a local idea shelf.

## Run
Open `index.html` in a browser. No build step, framework, API key, or server is required.

## Features
- Local idea generation from a topic, platform, and content style
- Save, copy, remove, and export ideas
- Editable thumbnail preview with four color themes and 1280×720 PNG export
- Title suggestions, a 7-day publishing plan, and a pre-publish checklist
- Responsive Persian RTL layout

## Privacy and limitations
This prototype uses browser localStorage for saved ideas. The idea generator is template-based and does not call an AI service. No login, cloud sync, or publishing integration is included.
